# Meta Mov website

Static one-page site for Meta Mov (@meta_mov), Riyadh.

- `index.html` — the whole page
- `img/` — logo and photos

**To add Instagram Reels:** open `index.html`, find `EDIT HERE` near the bottom, paste Reel links into `HERO_REEL` and `REELS`, commit. Vercel redeploys automatically.
